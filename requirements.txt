# BridgeCare Analytics — 30-Day Hospital Readmission Risk

![Python](https://img.shields.io/badge/Python-3.11-3776AB?logo=python&logoColor=white)

A machine learning pipeline that predicts which patients are likely to
be readmitted to the hospital within 30 days of discharge — a metric
hospitals are financially penalized on under CMS's Hospital Readmission
Reduction Program, and one that directly reflects care quality.

**[Live dashboard →](https://andrewdankyi.github.io/bridgecare-analytics/)**

> ⚠️ **Synthetic data only.** All patient records are generated by
> `generate_sample_data.py` and do not represent real patients or any
> real healthcare organization. Modeling approach is based on the
> structure of the public [UCI Diabetes 130-US Hospitals
> dataset](https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008),
> not its actual contents.

## Results

4 classifiers trained on a SMOTE-balanced training set, evaluated on a
held-out 20% test set (2,400 patients):

| Model | Test ROC-AUC | Test Accuracy | 5-fold CV AUC |
|---|---|---|---|
| **Logistic Regression** (best) | **0.875** | 79.5% | 0.892 ± 0.005 |
| Random Forest | 0.854 | 86.7% | 0.982 ± 0.002 |
| XGBoost | 0.847 | 89.0% | 0.984 ± 0.002 |
| Decision Tree | 0.783 | 83.8% | 0.918 ± 0.002 |

Logistic Regression generalizes best on unseen data (highest test
ROC-AUC) despite lower raw accuracy — the tree-based models show a much
larger gap between cross-val and test AUC, a sign they're fitting more
to the training distribution. Accuracy alone is a misleading metric
here: with an 11% positive class rate, a model that never predicts
"readmitted" would already score ~89% accuracy. ROC-AUC and recall are
the metrics that actually matter for this use case, since missing a
high-risk patient (a false negative) is more costly than an extra
follow-up call (a false positive).

At the default 0.5 threshold, the best model recalls 78.8% of true
readmissions at 32.3% precision — reasonable for a screening tool
whose false positives just mean an extra check-in call. The
optimal threshold (maximizing Youden's J) is **0.545**.

## Top drivers of readmission risk

SHAP values on the winning model, in order:

1. Time in hospital (length of stay)
2. Number of diagnoses
3. Prior inpatient stays
4. Number of medications
5. Emergency (vs. elective/urgent) admission

This matches clinical intuition: longer, more complex admissions with
more prior hospitalizations carry the highest risk — the same
pattern documented in CMS readmission research.

## Tech stack

- **Python** — pandas, numpy
- **scikit-learn** — preprocessing pipeline, Logistic Regression, Random Forest, Decision Tree
- **XGBoost** — gradient boosted comparison model
- **imbalanced-learn** — SMOTE class balancing (training set only, to avoid data leakage)
- **SHAP** — model explainability
- **PostgreSQL** — schema design (`schema.sql`)
