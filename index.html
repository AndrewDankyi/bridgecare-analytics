ML Pipeline Architecture
1
Data Ingestion & ETL
SQL schema loads synthetic EHR records. PostgreSQL extracts patient demographics, admission history, diagnoses, and medication data into structured tables.
PostgreSQLschema.sql
2
Feature Engineering
13 raw columns → 33 model-ready features via one-hot encoding of categoricals (age group, admission type, discharge disposition, insulin, HbA1c, diabetes med) plus scaled numeric features.
pandasNumPy
3
Class Balancing (SMOTE)
Target class (readmitted) is ~11% of records. SMOTE applied on training set only to prevent data leakage. Balanced ratio: 1:1 for training.
imbalanced-learn
4
Model Training & Comparison
4 classifiers trained on the SMOTE-balanced set (RF, XGBoost, LR, DT), evaluated on a held-out test set with 5-fold stratified cross-validation. Logistic Regression generalized best (test AUC 0.875 vs. 0.78–0.85 for the others).
scikit-learnXGBoost
5
Explainability (SHAP)
LinearExplainer generates per-patient SHAP values for the winning Logistic Regression model. Top drivers: length of stay, diagnosis count, prior admissions. Supports clinical interpretability for discharge planning.
SHAPmatplotlib
